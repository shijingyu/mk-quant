# 永续合约相关性工具

工具箱提供独立 USDT / USDC 永续合约页面，以同一组 20 个基础币种为候选。按 exchangeInfo 的 PERPETUAL / TRADING / quoteAsset 校验；USDC 页面删除当前没有可交易 USDC 永续合约的币种，不用 USDT 数据替代。使用公开 /fapi/v1/time、exchangeInfo、klines、fundingRate，不读取客户 API Key 或调用交易接口。1000SHIB 使用真实合约代码。

| 窗口 | 周期 | 已收盘 K 线 | 对数收益率样本 |
|---|---|---:|---:|
| 24 小时 | 15m | 96 | 95 |
| 7 天 | 1h | 168 | 167 |
| 30 天 | 4h | 180 | 179 |
| 90 天 | 1d | 90 | 89 |

UTC 对齐截止点，每个窗口的全部交易对采用同一时间网格。未收盘、缺口、重复、无效价格和上市历史不足不会补零。页面时间以北京时间显示。

对齐收盘价的 ln(Ct/Ct-1) 计算 Pearson 相关系数。OLS 含截距，ln(A)=α+β ln(B)+残差；Z 值采用残差的总体标准差。对残差估计 AR(1) 系数 φ，半衰期为 -ln(2)/ln(φ)，仅 0<φ<1 时报告。零方差、无有效均值回归估计均显示缺失。|Z|>=2 标为显著偏离，>=1 标为偏离，其余为接近均值。指标并不构成协整检验或交易指令。

参考页面：[BJF 配对交易](https://bjftradinggroup.cn/配对交易/)。窗口和指标遵循其公开说明，AR(1) 半衰期及标准差口径在本项目明确给出，未声称重现其未公开实现。

两个市场独立缓存、同一 API 进程通过互斥锁共用一个串行采集通道；请求串行并间隔至少 0.5 秒，沿用适配器超时和 Retry-After 冷却。快照每 15 分钟按访问需求刷新，页面轮询统一缓存。失败保留旧快照并标记过期；冷启动显示加载状态。页面关闭不取消已开始的采集，API 重启后缓存重新建立。矩阵、配对榜单、详情、曲线和半衰期单位全部随所选窗口切换。半衰期为相应周期的 K 线根数，不固定为小时。

实验明细支持区间与交易对组合筛选。决策匹配该币种的行情输入、意图或风控事件，保留组合上下文；旧 Parquet 按批扫描，筛选总数有限缓存，不全量载入内存。交易记录将买卖与持仓方向合并一列，桌面固定列宽，日期时间换行；多头绿色、空头红色，盈亏正负分色，零值保持中性。

工具箱内的网格计算器（`#toolbox`）、USDT 矩阵（`#toolbox/correlation`）与 USDC 矩阵（`#toolbox/correlation-usdc`）为独立栏目，可直接打开、刷新及前进后退。矩阵币种表头采用独立底色；自身相关的 1.00 使用中性紫灰色；选中配对及其对称单元格使用蓝色底与边框，并显示已选配对文字。榜单的接近均值、偏离、显著偏离分别使用绿色、琥珀色、红色标签，保留文字说明。

点击当前窗口榜单的任意行（或键盘激活配对按钮），会在当前窗口中选中配对与对称位置，显示详情并标记榜单选中行；若币种位于前 10 个之外，自动展开完整矩阵。点击矩阵也同步对应榜单行；切换窗口保留所选配对。选中配对的详情随行情快照刷新。Z 值采用参考页面的着色阈值：|Z| >= 2 红色加粗，1 <= |Z| < 2 琥珀色加粗，其余保持中性色；正值保留 + 号，缺失值显示 —。


## v1.5.0 配对研究面板

- 四档相关系数可直接切换窗口；详情显示当前窗口的 β、Z 值和半衰期，并可关闭。
- 标准化价格为各自首个收盘价 = 100，逐根绘制，不平滑。Z 曲线与指标使用同一窗口的 OLS β 和总体标准差，末点等于当前 Z 值；±2 和零线作为参考，不替代协整检验。
- 滚动相关系数使用最后 N 个对数收益率，N = min(60, max(10, floor(收益率样本数 / 3)))。因此四档分别为 31、55、59、29 根 K 线。该口径在本项目明确定义。
- 资金费率读取各币种最近两次实际结算记录，显示最近一次费率、北京时间和观测结算间隔；不假定永远为 8 小时。资金费率为当前最近结算值，不是历史窗口均值；不可用时显示缺失原因。
- `/api/tools/correlation?quote=USDT|USDC` 返回汇总；`/api/tools/correlation/pair?quote=…&window=…&a=…&b=…` 只从已完成缓存计算图表，无额外行情下载。两个接口都要求管理员权限。前端会核对图表与汇总快照版本。
- 控制台左上角显示前端发行版本 v1.5.0；交易引擎版本独立维护，此次没有更改撮合或实盘执行逻辑。
