# 工作台公共设计规则

界面以模拟交易页为样板，统一到实盘交易、用户管理、策略管理、回测及弹窗。令牌在 `frontend/src/design-system.css`，业务组件在 `frontend/src/App.jsx`，日夜切换保存在浏览器本地。

| 层级 | 日间规则 |
| --- | --- |
| 导航 | 石墨 `#152027`，宽 220px；总览、研究、交易运行、系统分组。 |
| 工作区 | 背景 `#F5F6F8`、工作面 `#FFFFFF`、边线 `#E3E7ED`。 |
| 文字 | 主文字 `#18222F`、次级 `#626F7E`，中文优先系统无衬线。 |
| 主要操作 | 深翡翠绿 `#146C54`，浅强调 `#EAF4EF`。 |
| 字级 | 页标题 28px、区域 16–18px、正文/输入/主表格 14px、辅助 12–13px。 |
| 金融数字 | 资产主值 34px、次级 26px，`tabular-nums`；数字与表头右对齐，代码字体仅用于代码/技术 ID。 |
| 尺度 | 工具栏 56px，横向留白 24–32px，区块间距 24px，控件 40px，卡片圆角 12px。 |

零值用中性文字，无数据用“—”并给出原因。收益与亏损、运行状态、模拟与实盘各有稳定颜色与文字；过期/异常信息不随主题隐藏。夜间使用完整独立文字/表面/状态令牌，不通过整页滤镜反色。无外部字体服务请求，系统回退保持一致。

## 公共组件

- `AssetOverview`：统一资产面板，账户总权益为主，浮盈亏、保证金占用、已平仓收益为次。
- `AccountTable` / `AccountActions`：同一账户行内查看、配置及更多菜单；手机改为账户卡片。更多菜单通过 portal 脱离滚动表格，支持方向键、Home/End、Escape及外部点击。
- `RecentOperations`：处理中和失败突出展示，已完成历史折叠；任务ID与所属账户保持关联。
- `Heading` / `Field` / `Modal`：统一标题、字段、错误反馈、间距及弹窗滚动；管理员资料弹窗保留退出，顶栏不再重复放置退出按钮。
- `Chart`：统一轴文字、网格、真实线条、提示框和主题；抽样预览明确标注，完整报表仍读全部数据。

## 页面布局

模拟与实盘页共享资产面板、主要账户表和近期操作；危险的批量操作独立分组，继续使用原有权限与双重确认。用户管理复用同一账户行操作，不再在表格下方重复账户按钮列表。

回测桌面布局左侧 360–420px 配置，右侧状态、核心指标和曲线；长配置可内部滚动，主要操作位置稳定，预设并入参数区。窄屏按配置、结果顺序排列，避免固定宽度溢出。

策略卡片以名称/版本/状态、短说明、紧凑属性网格及详情/编辑/回测组成，不用固定大空白撑高；协议和实现说明移到详情或帮助。

## 验收规则

在浏览器 100% 缩放，以 1440×900、1920×1080、390×844 分别检查模拟、用户、策略、回测，并保留同视口改版前后截图。额外检查夜间、移动菜单、行内更多菜单、客户预览/复制链接、策略详情、布尔参数和危险操作确认。

普通文字和占位文字目标对比度至少 4.5:1。检查实际计算样式和渲染，数字不使用缩小浏览器或缩小字体来适配表格；允许表格内部滚动，不允许整页横向溢出。收益语义、空值、接口契约、权限和北京时间转换须继续通过自动化与交互验收。

生产数据截图与数据库资料保留在私有验收目录，不随公开源码发布。
